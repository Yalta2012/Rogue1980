# Rogue 1980
Это упрощенная версия игры Rogue 1980 года.
Вам предстоит пройти случайно сгенерированное подземелье из 21 уровня.

## Управление:
- Посмотреть подсказку на i;
- Перемещение на WASD;
- Применение оружия из рюкзака h;
- Применение еды из рюкзака i;
- Применение элексира из рюкзака k;
- Применение свитка из рюкзака e.

## Противники:
- z - зомби;
- v - вампир;
- g - приведение;
- O - огр;
- S - змей-маг;
- m - мимик.
